# 🎨 [Mahashank AI Studio](https://your-app-name.streamlit.app)

> **Built by Mahashank Design and Technology Company**

A lightweight, permanent, and 24/7 high-definition generative AI web application engineered for commercial product mockups, saree portraits, and photorealistic human renders. Powered by **Streamlit** and running on **Cloudflare Workers AI** using the state-of-the-art `@cf/black-forest-labs/flux-1-schnell` model via REST API.

---

## ⚡ Features

- **Zero API Cost:** Leverages Cloudflare Workers AI free daily allowance.
- **Enterprise Speed & Uptime:** Instant inference powered by `@cf/black-forest-labs/flux-1-schnell`.
- **Hyper-Realistic Portrait Rendering:** Engineered prompts designed to eliminate artificial, plastic, or airbrushed AI artifacts by enforcing authentic skin textures, pores, and optical camera settings.
- **Direct Image Download:** Full-resolution JPEG export directly from the interface.
